# React Props

## Description

This project is an introduction to React components and props.

The goal is to learn how to create and reuse React components, pass data between components using props, and use basic React features such as fragments and conditional rendering.

## Learning Objectives

By the end of this project, I should be able to:

- Create basic React components using functions
- Reuse React components
- Pass properties to components using props
- Use React Fragments
- Use keys when rendering lists
- Understand basic conditional rendering

## Technologies

- React
- JavaScript
- Node.js
- npm
- Jest
- React Testing Library
