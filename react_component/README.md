React Component

This project focuses on building and testing reusable React components.

The goal is to understand how React components work, how their lifecycle is managed, how to optimize rendering, and how to test component behavior using Jest.

Learning Objectives

By the end of this project, I should be able to explain:

* When to use a class component or a functional component
* The lifecycle of a React class component
* How to test React components
* How to use Jest spies to verify function calls
* What Higher-Order Components (HOC) are and how to use them
* How to optimize component rendering and performance
* How to detect and handle changes in component props
* How to pass children through components

Concepts Covered

React Components

Components are reusable pieces of UI that allow an application to be split into independent and maintainable parts.

This project covers both:

* Functional components
* Class components

Component Lifecycle

Class components provide lifecycle methods that allow actions to be performed at different stages of a component’s existence, such as mounting, updating, and unmounting.

Pure Components

React’s PureComponent can help improve performance by preventing unnecessary renders when props and state have not changed.

Higher-Order Components

A Higher-Order Component is a function that takes a component and returns an enhanced version of that component.

HOCs can be useful for sharing reusable logic between several components.

Testing

Components are tested using Jest.

The project includes concepts such as:

* Mock functions
* Jest matchers
* Spies
* Testing component behavior
* Verifying function calls
* Checking changes in props
